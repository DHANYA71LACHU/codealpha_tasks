# Task 1: Biological Data Extraction Using BioPython

## Objective
Extract biological data from the NCBI database using BioPython and create a custom dataset for analysis.

## Tools Used
- Python
- BioPython
- Pandas
- NCBI Entrez API

## Project Description
This project retrieves biological data directly from the NCBI database using BioPython. It extracts protein sequence information and stores the results in a CSV file for further analysis.

## Files
- extract_spike_protein.py
- requirements.txt
- Spike_Protein_Dataset.csv

## Output
The output dataset contains:    
- Accession ID
- Protein Description
- Sequence Length
- Protein Sequence
