# Task 2: Exploratory Data Analysis (EDA) on Protein Dataset

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the protein dataset generated in **Task 1** using BioPython. The objective is to understand the dataset, identify patterns and trends, detect anomalies, and prepare the data for future bioinformatics and machine learning applications.

---

## Objectives

- Understand the structure of the protein dataset.
- Explore variables and their data types.
- Identify missing values and duplicate records.
- Analyze the distribution of protein sequence lengths.
- Examine organism-wise protein distribution.
- Investigate molecular weight variations.
- Detect outliers and anomalies.
- Study relationships between numerical variables using correlation analysis.
- Summarize key biological insights from the dataset.
