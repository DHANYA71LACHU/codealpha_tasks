# Task 4: Sentiment Analysis on Amazon Product Reviews

## Project Overview

This project performs sentiment analysis on Amazon product reviews using Natural Language Processing (NLP) techniques. The goal is to classify customer reviews as Positive, Negative, or Neutral and analyze customer opinions through text data.

The project demonstrates how sentiment analysis can be used to understand public opinion, customer satisfaction, and product feedback.

---

## Objectives

- Perform sentiment analysis on customer reviews.
- Classify reviews into Positive, Negative, and Neutral categories.
- Clean and preprocess textual data.
- Visualize sentiment distributions.
- Identify common words associated with positive and negative sentiments.
- Generate insights that support business and marketing decisions.

## Key Insights

- Most reviews are positive.
- Positive reviews frequently contain words such as "excellent", "good", and "quality".
- Negative reviews often include terms like "poor", "bad", and "disappointed".
- Sentiment analysis helps understand customer satisfaction and product performance.
