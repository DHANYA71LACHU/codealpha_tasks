# Task 3: Data Visualization on Protein Dataset

## Project Overview

This project focuses on transforming the protein dataset extracted in Task 1 into meaningful visualizations. Using Python visualization libraries, the project presents biological data through charts and graphs that help reveal patterns, relationships, and trends.

---

## Objectives

- Convert raw biological data into visual representations.
- Understand protein characteristics through graphs.
- Highlight trends and distributions within the dataset.
- Support biological interpretation using data visualization.
- Build a portfolio of professional scientific visualizations.

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Visualizations Included

- Protein Records by Organism
- Protein Sequence Length Distribution
- Molecular Weight Distribution
- Sequence Length Boxplot
- Correlation Heatmap
- Sequence Length vs Molecular Weight Scatter Plot
- Organism Distribution Pie Chart

---

## Applications

- Bioinformatics
- Protein Analysis
- Scientific Reporting
- Biological Data Visualization
- Data Analytics
